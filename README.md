## Data Science Projects

### 1. Customer Churn Prediction & Retention Prioritization

**Tech Stack:** Python, Pandas, Scikit-learn, XGBoost, Matplotlib

- Analyzed the IBM Telco Customer Churn dataset (~7,000 records, 21 columns).
- Performed data cleaning, exploratory data analysis, one-hot encoding, and feature preprocessing.
- Implemented an 80/20 stratified train-test split.
- Trained and compared Logistic Regression, XGBoost, and class-weighted XGBoost.
- Evaluated model performance using Accuracy, Precision, Recall, F1-score, ROC-AUC, and PR-AUC.
- Developed a cost-benefit analysis to prioritize customers based on predicted churn probability.

**Model Performance**

| Model | Accuracy | F1 | Precision | Recall | ROC-AUC |
|---|---:|---:|---:|---:|---:|
| Logistic Regression | 0.807 | 0.606 | 0.661 | 0.559 | 0.842 |
| XGBoost | 0.776 | 0.553 | 0.589 | 0.521 | 0.818 |
| Balanced XGBoost | 0.757 | 0.595 | 0.534 | 0.671 | 0.819 |

**Key Findings**

- Logistic Regression achieved the highest Accuracy, F1-score, Precision, and ROC-AUC.
- Balanced XGBoost achieved the highest Recall, identifying more actual churners at the expense of Precision.

**Business Impact**

- Used an assumed ₹500 retention-offer cost and ₹2,000 customer lifetime value.
- Model-based top-10% targeting generated an estimated net value of **₹133,411**, compared with **₹4,912** for random targeting (averaged over 100 random draws) — a difference of **₹128,500**.
- Lift@10% = **2.83x**.
